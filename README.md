# Herdr for Tern

Your Herdr sessions, right inside Tern.

Pick a session and keep going. Herdr keeps its own workspaces, tabs, panes, and running programs. Nothing gets copied or converted.

## Get started

You'll need desktop Tern, Git, and Herdr, with `herdr` on Tern's PATH.

```sh
tern plugin install github.com/gabrielmoreira/herdr-tern-plugin
```

Open Tern's command palette, choose **Open Herdr Session**, and pick your session.
