# Herdr for Tern

**Your Herdr sessions now live in Tern.**

Keep working where you already are. Browse every session, peek inside without opening anything, and bring a whole one over — workspaces, tabs, panes, the exact programs in the exact directories — in a couple of clicks. Into a fresh session, or right into one that's already open. Your pick.

Herdr never stops running. It's a copy, not a move.

## Get started

```sh
tern plugin install github.com/gabrielmoreira/herdr-tern-plugin
```

Open Tern's palette and choose **Open Herdr in a Tab** or **Import Herdr Session into Tern**.

## The fine print

- Mirrored panes run the same program in the same directory; exact split ratios are not reproduced.
- On Windows, a console window flashes on each refresh — Tern spawns plugin children without `CREATE_NO_WINDOW`. Details, and the fix we asked Tern for, in [TERN-PLUGIN-FEEDBACK.md](TERN-PLUGIN-FEEDBACK.md).
